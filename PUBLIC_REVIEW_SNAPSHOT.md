# Public Review Snapshot

This repository is a temporary, single-commit portfolio snapshot of Avalon Q Scheduler prepared for admissions review.

It includes the scheduler source, tests, example configuration, technical documentation, and the historical F2Pool settlement dataset retained with the owner's approval. It intentionally excludes the private Git history, local credentials, OAuth and Tesla token stores, machine-specific `config.yaml`, runtime state, logs, generated outputs, and internal agent instructions.

The complete operational repository remains preserved privately. This public snapshot is not the deployment remote used by the running scheduler.
